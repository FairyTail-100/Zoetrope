# Security Policy

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities using **GitHub Private Vulnerability Reporting**:
1. Go to https://github.com/FairyTail-100/Zoetrope/security/advisories/new
2. Provide a clear description of the issue, reproduction steps, and potential impact.

We will acknowledge receipt and work on a fix before any public disclosure.
