01 // Architecture

Ascenta Engine Rebuilt

A framework-agnostic scroll animation engine for smooth scroll-driven motion. Avoids browser seek bottlenecks and memory crashes through predictive asset streaming and directional LRU caching.

02 // Memory Architecture

Directional LRU Caching

Uncompressed 1080p frames consume 8.29MB of RGBA memory each. Our directional cache applies an asymmetric penalty multiplier to frames behind the scroll cursor, retaining forward frames eagerly while keeping mobile WebKit well below Jetsam eviction thresholds.

03 // Streaming Container

Asset Streaming Pipeline

Supports individual frame WebP/AVIF streaming by default, with opt-in CEPK binary bundling. Decoded asynchronously off the main thread with zero layout jank.

04 // Motion Normalization

MotionLUT Curves

Linear scroll mapping creates unnatural visual acceleration during variable-speed camera moves. Our engine evaluates a 1D monotonic motion lookup table, translating physical wheel travel into calibrated visual displacement.
